# Exercise IV datasets

Public teaching data were downloaded on 2026-11-01. Exact upstream URLs, file sizes, and SHA-256 checksums are recorded in `sources.json`. The notebook uses local copies and downloads a missing input from its original URL.

- `usa-cities.geojson`, `dc-roads.geojson`, `nyc-boroughs.geojson`, and `nyc-collision-factors.geojson`: [GeoPlot example datasets](https://github.com/ResidentMario/geoplot-data).
- `shade.tif`: [Rasterio test raster](https://github.com/rasterio/rasterio/blob/main/tests/data/shade.tif).
- `columbus.csv`: [GeoDaSpace Columbus example](https://github.com/GeoDaCenter/GeoDaSpace/blob/master/econometrics/examples/columbus.csv).

The NYC collision file has 7303 unique records from 2016 and is preselected to two first-vehicle contributing factors: Failure to Yield Right-of-Way and Lost Consciousness. It is not the complete NYC collision registry. The notebook documents missing ZIP handling, the exact vehicle categories, and whether any contributing factor or the first vehicle's factor defines the target.

The following CSVs are generated by the bonus analysis:

- `nyc_zip_aggregates.csv`: retained ZIPs, collision counts, indicator counts, mean coordinates, and proportions.
- `nyc_zip_test_predictions.csv`: actual and predicted proportions for the 32 eastern test ZIPs.
- `nyc_zip_model_scores.csv`: held-out MAE and RMSE for OLS, SAR, and a training-mean baseline.
